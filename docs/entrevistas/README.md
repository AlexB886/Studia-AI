# Entrevistas de validación

Aquí guardamos las entrevistas que hagamos a estudiantes para validar
Studia-IA. **Sin apellidos ni teléfonos**: solo nombre de pila o iniciales,
edad/estudios y lo que cuentan.

## Cómo hacer una entrevista (10–15 min)

1. Preguntar cómo organiza hoy sus tareas y su estudio.
2. Preguntar qué métodos de repaso usa y qué le falla.
3. Enseñar la demo: crear una tarea, organizar un examen, planificar una
   sesión y hablar con Luna.
4. Cerrar con las tres preguntas de abajo.

## Plantilla (copiar este bloque por cada entrevista)

```markdown
### Entrevista nº __ — [nombre o iniciales], [edad] — [estudios/ciclo]
- **Fecha:** __/__/2026
- **Quién entrevista:** [miembro del equipo]

**1. ¿Cómo organizas hoy tus tareas y tu estudio?**
> (respuestas aquí)

**2. ¿Cómo repasas? ¿Qué métodos usas y qué te falla?**
> (respuestas aquí)

**3. Después de probar la demo:**
- ¿Entiende cómo usar la app? (sí / no / a medias):
- ¿Qué le ha parecido útil?
- ¿Qué cambiaría o le falta?
- ¿Volvería a usarla? (sí / no / quizá):
```
